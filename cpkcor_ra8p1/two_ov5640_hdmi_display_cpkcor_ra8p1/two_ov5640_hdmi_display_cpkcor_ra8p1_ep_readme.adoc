configuration.xml 中与屏幕有关的 stack 如下：

g_i2c_master0 用于读写 RGB 转 HDMI 输出的芯片 TFP410 的寄存器。g_lcdc_tfp410 配置 GLCDC 如何输出 RGB 格式的信号。为了解释此工程的实现方式，下面会先介绍 GLCDC 屏幕显示画面合成的方式，下图是 GLCDC 对屏幕的定义：

[.text-center]
--
image::Snipaste_2026-10-16_13-49-04.png[role="thumb"]
--

图中黑色的矩形即为一个屏幕，橙色区域对应屏幕实际的可显示区域，蓝色部分则对应 GLCDC 的显示层区域。可显示区域与完整的屏幕间还有同步时钟、消隐前沿、消隐后沿参数，对于一般的 RGB 屏幕来说，这些参数需要根据使用的驱动芯片的数据手册来设置。当前例程是使用 TFP410 将 GLCDC 的 RGB 输出转为 HDMI，此时这些参数的设置需要根据 HDMI 的显示标准来填写，例程中已根据标准填写一组参数，将 HDMI 输出的格式设置为了 1280x720 @54Hz，相关参数可以点开 g_lcdc_tfp410 stack，在属性界面依次点开 `Output -> Timing` 和 `Output -> Format` 查看。

GLCDC 将可显示区域再次分为垂直的三层：

* 图层二：大小可在指定范围内任意设定，不一定要与屏幕可显示区域的大小一致。GLCDC 将范围限制为水平、垂直方向都为 16-2040 像素
* 图层一：大小可在指定范围内任意设定，不一定要与屏幕可显示区域的大小一致。GLCDC 将范围限制为水平、垂直方向都为 16-2040 像素
* 背景层：大小固定为屏幕的可显示区域的大小，该层的颜色在 `Output -> Background` 进行配置

图层一和二还能设置相对于屏幕可显示区域起点的位置。显示时，颜色从上往下覆盖，不被图层一和二覆盖的区域，则显示背景层的颜色。根据 GLCDC 的特性，可以将图层一设为屏幕的一半大小，放置于左侧，图层二也设置为屏幕的一半大小，放置在右侧，那么 GLCDC 就会自动将两个摄像头的画面分别显示在屏幕的左右两侧。下面是图层的具体配置：

VIN 外设有三个接收缓冲地址槽位，MB1、MB2、MB3，当 VIN 启动后，硬件会自动按照 MB1->MB2->MB3->MB1 的顺序写入捕获的图像，因此当前例程直接配置三个缓冲区，显示时，在这三个缓冲区中轮换，以获得较好的显示效果。

=== 驱动文件：屏幕

与屏幕有关的驱动文件位于 `src/lcd` 文件夹下。屏幕的使用较为简单，配置逻辑与 FSP 对外设的配置逻辑类似：

* 定义控制结构体和配置结构体变量：

[source,c,subs="verbatim,attributes"]
----
static LCD_DeviceType s_lcd_tfp410;
static LCD_ConfigType s_tfp410_cfg;
----

* 填写配置结构体的字段，然后调用初始化

[source,c,subs="verbatim,attributes"]
----
s_tfp410_cfg.model = LCD_MODEL_TFP410PAPR;
s_tfp410_cfg.peri_1 = &g_lcdc_tfp410;
s_tfp410_cfg.peri_model_1 = LCD_PERI_GLCDC;
s_tfp410_cfg.peri_2 = NULL;
s_tfp410_cfg.peri_model_2 = LCD_PERI_UNUSED;
s_tfp410_cfg.iicWrite = tfp410IicWrite;
s_tfp410_cfg.iicRead = tfp410IicRead;
err = LCD_Initialize(&s_lcd_tfp410, &s_tfp410_cfg);
HANDLE_ERROR(err, "LCD_Initialize() failed: %u", err);
----

=== 驱动文件：摄像头

与摄像头有关的驱动文件位于 `src/camera` 下。配置逻辑也与 FSP 对外设的配置逻辑类似。当前例程使用的是两个 OV5640 摄像头，它们的 I2C 地址相同，且挂在了用一个 I2C 总线上，因此需要利用 PowerDown 功能来分时复用。

[sidebar]
****
TIP: PowerDown 功能由 OV5640 的 PWDN 引脚控制，拉高时，OV5640 进入掉电模式，此时不会对 I2C 接口进行响应，但寄存器的配置会保留
****

* 定义控制结构体和配置结构体变量：

[source,c,subs="verbatim,attributes"]
----
static Camera s_camera_ov5640_dvp;
static Camera s_camera_ov5640_mipi;

void hal_entry(void)
{
    ...
    CameraConfig ov5640_config_dvp;
	CameraConfig ov5640_config_mipi;
    ...
}
----

* 对 DVP 接口的 OV5640 进行配置，并在配置完成后进入 PowerDown 状态

[source,c,subs="verbatim,attributes"]
----
ov5640_config_dvp.model = CAMERA_MODEL_OV5640;
ov5640_config_dvp.interface = CAMERA_INTERFACE_DVP;
ov5640_config_dvp.length = g_ceu_ov5640_cfg.x_capture_pixels;
ov5640_config_dvp.width = g_ceu_ov5640_cfg.y_capture_pixels;
ov5640_config_dvp.peripheral_inst = &g_ceu_ov5640;
ov5640_config_dvp.buffer_1 = s_dvp_image_1;
ov5640_config_dvp.buffer_2 = s_dvp_image_2;
ov5640_config_dvp.buffer_3 = s_dvp_image_3;
err = CameraInit(&s_camera_ov5640_dvp, &ov5640_config_dvp);
HANDLE_ERROR(err, "OV5640 DVP interface init failed: %u", err);
err = CameraSetFPS(&s_camera_ov5640_dvp, 30, NULL, false);
HANDLE_ERROR(err, "OV5640 DVP interface set FPS failed: %u", err);
R_BSP_SoftwareDelay(20, BSP_DELAY_UNITS_MILLISECONDS);
CameraPowerDown(&s_camera_ov5640_dvp, 1);
----

* 对 MIPI CSI 接口的 OV5640 进行配置

[source,c,subs="verbatim,attributes"]
----
ov5640_config_mipi.model = CAMERA_MODEL_OV5640;
ov5640_config_mipi.interface = CAMERA_INTERFACE_MIPI_CSI;
ov5640_config_mipi.length = g_vin_ov5640_cfg_extend.conversion_data.uds_clipping_bits.cl_hsize;
ov5640_config_mipi.width = g_vin_ov5640_cfg_extend.conversion_data.uds_clipping_bits.cl_vsize;
ov5640_config_mipi.peripheral_inst = &g_vin_ov5640;
err = CameraInit(&s_camera_ov5640_mipi, &ov5640_config_mipi);
HANDLE_ERROR(err, "OV5640 MIPI interface init failed: %u", err);
err = CameraSetFPS(&s_camera_ov5640_mipi, 30, NULL, false);
HANDLE_ERROR(err, "OV5640 MIPI interface set FPS failed: %u", err);
R_BSP_SoftwareDelay(20, BSP_DELAY_UNITS_MILLISECONDS);
----

* 恢复 DVP 接口的 OV5640，并开始捕获

[source,c,subs="verbatim,attributes"]
----
CameraPowerDown(&s_camera_ov5640_dvp, 0);
err = CameraStartCapture(&s_camera_ov5640_dvp, NULL);
HANDLE_ERROR(err, "OV5640 DVP interface start capture failed: %u", err);
err = CameraStartCapture(&s_camera_ov5640_mipi, NULL);
HANDLE_ERROR(err, "OV5640 MIPI interface start capture failed: %u", err);
----

[sidebar]
****
TIP: 在通过 I2C 接口配置完摄像头后，如果没有进入 PowerDown 状态，摄像头就已经在输出图像了，`CameraStartCapture()` 所做的只是启动 CEU 或者 VIN 开始接收数据，所以此时可以先恢复 PowerDown
****

* 最后，在 while 循环中，判断摄像头是否捕获完成，如果完成了，就向 GLCDC 更新捕获完成的内存地址

[source,c,subs="verbatim,attributes"]
----
while (1) {
    if (CameraIsCaptureDone(&s_camera_ov5640_mipi)) {
        if (s_camera_ov5640_mipi.image_ready == NULL) {
            continue;
        }
        err = LCD_UpdateLayer1Mem(&s_lcd_tfp410, 1, s_camera_ov5640_mipi.image_ready, true, false);
        if (err) {
            continue;
        }
        err = LCD_Present(&s_lcd_tfp410, 1);
        if (err) {
            LOG_E(__FUNCTION__, "Layer 1 present failed: %u", err);
        }
    }
    if (CameraIsCaptureDone(&s_camera_ov5640_dvp)) {
        if (s_camera_ov5640_dvp.image_ready == NULL) {
            continue;
        }
        err = LCD_UpdateLayer2Mem(&s_lcd_tfp410, 1, s_camera_ov5640_dvp.image_ready, true, false);
        if (err) {
            continue;
        }
        err = LCD_Present(&s_lcd_tfp410, 2);
        if (err) {
            LOG_E(__FUNCTION__, "Layer 2 present failed: %u", err);
        }
    }
}
----
